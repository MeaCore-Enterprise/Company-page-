# **App Name**: MeaCore Digital Solutions

## Core Features:

- Landing Page: Presenta una propuesta de valor clara orientada a conversión, destacando desarrollo de software, automatización y soluciones MVP.
- Service Listing: Muestra los servicios ofrecidos con enfoque en beneficios concretos y resultados para el cliente.
- Pricing Plans: Incluye tres planes — Basic, Professional y Enterprise — con precios visibles y llamados a la acción claros.
- Portfolio Display: Sección de portafolio con un mock-up estático de un dashboard de producto (visual, no funcional).
- Contact Form: Formulario interactivo con validación del lado del cliente para asegurar envíos completos.
- Firestore Integration: Área dinámica que muestre datos de ejemplo simulando una base de datos Firestore, como si fueran métricas o información en tiempo real.

## Style Guidelines:

- Color primario: Azul `#2E86C1` (confianza e innovación).
- Fondo: Gris claro `#F5F5F5` para un diseño limpio y moderno.
- Color acento: Azul claro `#5DADE2` para jerarquía visual.
- Tipografía: Inter, sans-serif, para cuerpo y títulos.
- Usa un sistema de grilla responsive que funcione correctamente en desktop y mobile.
- Aplica animaciones y transiciones sutiles al navegar entre secciones y al cargar datos.
